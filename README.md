# interactive-map
خريطة تفاعلية لعرض البيانات المكانية باستخدام البايثون
# 🚀 من ملف Text بسيط إلى خريطة تفاعلية باستخدام Python و GIS!

في هذا المشروع التدريبي، قمت بتحويل بيانات خام عن محافظات مصر إلى بيانات مكانية قابلة للتحليل والعرض التفاعلي.

---

### 📄 البيانات المستخدمة
بدأت بملف نصي (Text) يحتوي على بيانات لمحافظات مصر، شملت:
* 📍 **الإحداثيات الجغرافية**
* 👥 **عدد السكان**
* 📏 **المساحة**
* 📊 **الكثافة السكانية**
* ⛰️ **الارتفاع**

---

### ⚙️ مسار العمل (Workflow)
بنيت مسار عمل باستعمال **Python** و **ArcGIS Pro** شمل الخطوات التالية:

1. **قراءة وتنظيم البيانات**
2. **تنظيف ومعالجة البيانات** باستخدام سكريبتات Python.
3. **تحويل البيانات إلى صيغة JSON**.
4. **تحويل الإحداثيات إلى نقاط جغرافية (Geographic Points)**.
5. **عرض البيانات داخل ArcGIS Pro**.
6. **تصنيف الكثافة السكانية وتمثيلها بصريًا**.
7. **إنشاء خريطة تفاعلية باستخدام مكتبة Folium**.
